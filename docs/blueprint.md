# **App Name**: FinanceFlow

## Core Features:

- Daily Record Creation: Allows users to input daily financial records, including opening balances, payments, and closing balances.
- Automated Summaries: Generates daily, weekly, and monthly summaries of financial data, providing insights into spending patterns.
- Balance Alerts: Sends low balance alerts to users based on predefined thresholds to help avoid overdrafts or budget overruns.
- Data Export: Allows users to export their financial data in common formats (e.g., CSV) for external analysis or backup.
- Database storage: Store the opening balances, closing balances, and the transactions

## Style Guidelines:

- Primary color: Forest green (#3F704F), evokes a sense of growth and stability.
- Background color: Soft beige (#F5F5DC), providing a neutral and calming backdrop.
- Accent color: Burnt orange (#CC6633), highlighting key actions and important data points.
- Body font: 'PT Sans', a humanist sans-serif, for readability and a modern feel.
- Headline font: 'Alegreya', a humanist serif, providing a touch of elegance for titles.
- Simple, line-based icons representing each category (e.g., food, transport) for clarity.
- Clean, minimalist design with a focus on readability and easy data input.
- Subtle transitions and animations to enhance user experience without being distracting.
